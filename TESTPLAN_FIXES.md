5. Submit form
6. **Expected:** No validation error, payment saved

### Scenario 2: Edit Payment Status
1. Go to BetalingPagina
2. Click edit on any payment
3. Change status to "In Afwachting"
4. Save
5. **Expected:** Status changes successfully

1. Login as Lid
2. Go to Lidpagina
